
# Predictive Maintenance System

An End-to-End Predictive Maintenance project using
Machine Learning and MLOps.

## Project Overview

This project aims to predict the Remaining Useful Life
(RUL) of industrial equipment using sensor data.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- PyTorch
- MLflow
- FastAPI
- PostgreSQL
- Docker
- GitHub Actions

## Project Structure


Currently in development.

## Dataset

NASA C-MAPSS Turbofan Engine Degradation Dataset.
